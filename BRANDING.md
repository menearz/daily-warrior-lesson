# Branding

Daily Warrior's Lesson is dark, full-width, and uncropped.

- Background `#0B0D10`
- Surface `#1B2028`
- Accent `#FF6A1A`
- Ink `#E7E9EC`
- Lesson images stay full width. Never crop the hero to a square tile.
- Type is system UI sans. No novelty fonts.

App identity for the stores:

- App name: Daily Warrior's Lesson
- Application ID / bundle ID: `com.menearz.dailywarrior`
- Short name: Warrior's Lesson
